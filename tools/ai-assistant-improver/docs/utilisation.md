# Utilisation - AI Assistant Improver

## Ouvrir la page de réglages

Ouvrir **Settings / Preferences** (`Ctrl+Alt+S`), puis la section **AI Assistant Improver**.

## Assistants

La page affiche le catalogue fixe : **Cursor**, **Claude**, **OpenCode**, **Junie**. Aucun assistant n'est actif tant qu'on ne le coche pas.

- Cocher un assistant l'active pour le projet ouvert.
- Décocher un assistant le désactive et laisse en place les fichiers déjà installés pour cet assistant.
- Seuls ces quatre identifiants sont proposés ; un identifiant hors catalogue n'apparaît pas et est refusé par le modèle.

## Langue

Le choix de langue propose l'**anglais** (valeur de départ) et le **français**. Ce réglage s'applique à l'ensemble de l'IDE, pour tous les projets.

Les assistants activés, eux, sont un réglage du projet ouvert : chaque projet a sa propre liste d'assistants actifs.

Les deux réglages se modifient sur cette même page. Les libellés affichés (titres, noms d'assistants, messages) viennent du bundle de la langue choisie.
